# 阿尔法掼蛋狗

一个可以实际走完单副牌、逐步复盘和另开分支重打的中文掼蛋练习程序。规则校验与回放在浏览器执行；在线版默认使用快速本地策略，智能对战可选 MiniMax M3.1 Flash 决策，并提供按需点评与配音。

## 开始使用

- 双击项目根目录的 `阿尔法掼蛋狗.html`，可以离线使用。
- 运行 `npm run dev -- --port 8769 --hostname 127.0.0.1`，打开 `http://127.0.0.1:8769`。
- 直接开始一副实战。点击手牌，确认牌型声明，出牌；回车可确认出牌。
- 点击「思路提示」比较候选动作。「电脑观摩」让电脑代打你的位置，时间线会注明来源。
- 语音默认开启，首次点击或键盘操作后解锁浏览器发声。播报座位、牌型、下一位行动者、借风和结束结果；桌面设置可静音、调速或重播。
- 电脑等待播报结束再行动；暂停、回放、换页与新局会取消旧播报。设备声音或浏览器限制仍可能导致无声。
- 点击时间线任意一行查看该步决策。左右方向键逐步前后回放；「查看全牌」提供明确标注的事后视角。
- 「从决策点另开分支」回到当前或此前最近的本人决策点，保留原局。分支牌局使用相同的初始发牌。
- 每一步的复盘笔记输入即保存。JSON 导出包含初始牌、全部动作、配牌声明、行动来源、分支父编号和笔记；导入时重新校验整段动作。

## 建议的 15 分钟练法

1. 理清整手牌，选择本局要关注的打法。
2. 打一副牌，只关注一个主题，例如「搭档控牌时是否需要接管」。
3. 找两手不确定的选择，写下当时的理由和现在的反思。
4. 查看全牌之前先比较当时可讨论的方案，再从一个节点分支重打。
5. 下一次重点检查同类局面是否能独立判断；不要只用单副胜负评价进步。

## 实现与边界

- `public/practice/engine.js`：108 张物理牌标识、固定级牌规则、配牌声明、合法动作、借风与名次、确定性发牌、回放、导入校验、规则策略电脑。
- `public/practice/lessons.js`：8 个自编精选局面，规则基础与策略讨论分别标记。教学局面不是完整发牌。
- `public/practice/speech.js`：公开动作的中文口播、浏览器语音控制、中断和超时恢复。依据 [SpeechSynthesis](https://developer.mozilla.org/en-US/docs/Web/API/SpeechSynthesis) 与 [SpeechSynthesisUtterance](https://developer.mozilla.org/en-US/docs/Web/API/SpeechSynthesisUtterance) 接口实现。
- `public/practice/app.js`、`styles.css`、`index.html`：纯前端界面与浏览器存储。
- `build.mjs`：将 CSS 和 JS 打包进可双击打开的单文件 HTML。
- 电脑和教练通过 `observe` 获得自身手牌及公开信息，不读取其他玩家隐藏手牌。本地模式使用启发式结构评分；在线对战由 MiniMax 从规则引擎给出的有限候选中选择。两者都不是专门训练的掼蛋高手模型或完整博弈求解器，尚未经专业教练审校。
- 本版固定级牌练单副，不模拟跨副进贡、还贡、升级赛程。首发可设置，升 1/2/3 级只作结果说明。
- 规则中的过牌、两张红心配牌独立成对等按「规则与方法」中列出的固定约定。赛事细则可能不同。
- 枚举提示对部分配牌、花色组合做了简化，不保证最优策略。合法选牌校验独立按所选实际牌张执行。
- 程序生成的模拟实战过程是真实执行的状态迁移，不是预先写死的剧情。它不连接第三方游戏平台，不识别真实牌桌视频，不支持多人联网。
- 数据保存在当前浏览器的当前站点存储，最近保留 20 副档案。清理浏览器数据、切换地址或设备不会自动迁移；请导出重要牌谱。离线文件的存储支持取决于浏览器。
- 在线版采用公开链接访问，各人的牌谱保存在自己的浏览器。分享链接不共享档案。AI 对战、点评与配音产生 MiniMax API 使用费；本地快速模式与本地规则复盘不调用决策模型。

## 验证

`npm test` 检查规则边界、配牌多义、炸弹层级、过牌与借风、结束条件、信息隔离、8 个题目目标、损坏牌谱拒绝、分支保留和笔记元数据。规则回归覆盖 65 副跨 13 种级牌的完整对局、5,321 次动作检查合法性、108 张牌守恒、终止和逐步回放一致性。

界面检查覆盖实际选牌及牌型声明、完整自动对局、训练反馈、逐步回放、明牌视角、分支、笔记、JSON 导出再导入和窄屏布局。实际手机触控及专业牌技质量未做人工验收。

所有视觉元素为本项目 CSS 和文字，使用系统字体，无外部图片或字体依赖。

离线单文件已检查 8 段内联脚本语法及零外部代码依赖。浏览器工具不允许直接打开 file 协议，未直接打开离线文件验收；界面验证使用本地 HTTP 预览。详细记录见 `test-artifacts/validation.json`。

## 在线对战与复盘（v1.8）

- 双站同步发布：数字殿堂 `https://shuzidiantang.com/games/guandan/` 与 Sites 原站（含 `https://guandan.shuzidiantang.com/practice/`）保持同一功能版本。每次修改均需同步两站、逐文件核对前端并验证各自 API。两站牌谱按浏览器来源分别保存，跨站需导出/导入。
- 数字殿堂入口：`https://shuzidiantang.com/games/guandan/`。前端、`/api/guandan/{battle,review,speech}` 与缓存均部署到数字殿堂 EdgeOne，运行不依赖 Sites。正式发布须核对线上版本与 API；本文件不是发布成功凭证。
- 正式仓库为 `historyreview-code/shuzidiantang`，当前迁移工作树 `/private/tmp/shuzidiantang-guandan`。后端源代码在 `cloud-functions/_guandan`，入口在 `cloud-functions/api/guandan`。
- 在线默认三个电脑席使用 MiniMax M3.1 Flash；桌面设置可切为本地快速策略。模型只收到当前席位手牌、各席张数、公开出牌与最多 20 个合法候选，真实搭档为 `(seat + 2) % 4`。不会收到其他手牌、个人笔记或未来行动。
- 模型返回候选编号、简短决策理由、搭档配合与后续计划。服务端和浏览器都验证合法性；理由并非规则事实或完整思考过程。逐步复盘及 JSON 导出保留这些说明和实际来源。
- 可以直接出完或只剩一种候选时由规则处理，标记为规则来源。模型错误或超时明确提示本地接替；不伪装成模型决策。暂停、初始理牌、回放和换局不会被旧异步结果推进；局中理牌可与其他席位的行动并行。
- 默认 `MiniMax-M3.1-Flash` 对战，medium 思考强度，最多 4096 输出 token，服务端 45 秒、前端 55 秒超时。模型与强度可用 `MINIMAX_BATTLE_MODEL` / `MINIMAX_BATTLE_EFFORT` 配置。
- 点评保持事实校验与模型意见分开，整局精选最多 3 个决策。输出 8192 token 上限，截断或格式错误只重试一次精简任务；不显示模型思考，也不把截断片段送回模型。
- 用户已取消每日与同网络次数上限，正式运行 `AI_UNLIMITED=true`。EdgeOne Blob 缓存逻辑有效期 7 天，定时清理超过 8 天的数据文件；跨实例不能保证并发相同请求只计费一次。费用与平台资源限制仍按账户实际使用计。
- 生产密钥为 EdgeOne 后端 `GUANDAN_MINIMAX_API_KEY`，经 GitHub secret 配置；本地开发沿用忽略的 `.dev.vars`。不进入网页或牌谱。
- 原 Sites 站点的档案不会随域名自动迁移。在旧站「复盘档案」或「桌面设置」导出 JSON，再到新站导入，原局保留。

## 理牌、同花顺与配音

- v1.8 移除随局教练栏，AI 点评、同花顺助手与决策拆解收进默认折叠的辅助工具；点击提示或进入复盘时展开。
- v1.7 取消分组框与“另起一组”，所有手牌连续排列。直接拖动牌面即可插到另一张牌之前或之后，包含红桃配牌；跨行、末尾和牌间空白处均可放下。自由顺序自动保存，旧分组转换为连续顺序。支持撤销；已出的牌不会因撤销回来。
- 出牌栏位于牌桌正下方、手牌上方，滚动手牌时保持可见。初始点击“完成理牌，开始出牌”，局中点击“完成理牌，返回出牌”；平时点牌选择、点击“出牌”，拖动只调整排列。理牌模式可点选多张（再次点击取消），拖动任一选中牌整体换位，按当前排列保留相对顺序；也可整组前后移，或取消选择。出牌模式继续直接拖单张，避免误移动已选出牌。
- 局中理牌时其他席位继续行动；轮到本人时等待退出理牌。拖动期间短暂等待避免刷新打断。手牌排列与牌谱独立，不提前固定配牌含义；有多种合法解释时在出牌栏选择“配牌方式”，实际声明保留在回放。
- 同花顺助手包含天然与配牌补位，默认折叠；选中方案仍需确认合法声明。排列与理牌中的选中状态不等于实际出牌。
- 在线牌局与点评继续用 `speech-2.8-hd` / `Chinese (Mandarin)_Reliable_Executive`，生成语速 0.96。首次交互解锁默认声音，桌面设置可静音、调速或重播。当前 MP3 缓存为 EdgeOne Blob。
- 语音接口只接受规则播报白名单或已生成点评的编号；不接受任意文稿。离线单文件仍使用设备语音。

## v2.0 阿尔法掼蛋狗（2026-10-24，当前部署约定）

正式入口仅为 https://shuzidiantang.com/games/guandan/ 。Sites 旧版已部署停用页，battle/review/speech 的 GET 和 POST 均返回 410，已移除旧站 API 密钥；禁止再把运行版同步回 Sites，除非用户明确恢复。

手机首页只保留牌桌、手牌、底部出牌操作。专题训练、规则导航、分享入口已移除。默认快速本地决策；首页可切换智能对战。催促出牌取消当前前端 AI 等待并立即使用本地合法动作，晚到结果不得落子；服务端已经发出的请求可能仍计费。默认语音开启，尊重用户此前静音偏好和浏览器首次交互要求。记录管理路径为“菜单 → 更多 → 记录管理”。

首次实际头游时给予 2.8 秒的烟花与鼓励文字，不拦截操作、不会在回放重复触发，遵循减少动态效果设置。理牌支持多选整体拖动和自由相邻排序。

策略版本 team-plan-v4；battle-v4 / review-v5 统一预设整手拆解、炸弹配牌机会成本、报单报双防守、搭档交棒与条件收尾路线。候选结构会计算互不占牌的炸弹保留组合、预计余牌手数和保守控牌条件；不是最优拆分或博弈均衡求解。整局点评有明确五项策略计划，仍只精选最多三个决策深入分析，不声称算完所有分支。所有座位只读取自己的手牌和公开信息。

规则依据见 [东南大学比赛规则](https://xxgk.seu.edu.cn/_upload/article/files/44/c8/f455e1d04d2a998e40454931740a/4f853bb4-29b9-45dc-9c56-7627ed4c9726.pdf)；策略优先级是程序推导，未经高手对战基准证明。
