# 吉林明清船厂与黑龙江航行

公开入口：`/maps/jilin-shipyards/`。首页轮播、作品列表、研究栏目、地图馆和 sitemap 均有入口。

## 内容与地图

- 六节历史正文、年代提要、五项考据说明、十九条文献及底图来源；下载稿为 `maps/jilin-shipyards/report.md`。
- 主图用 Natural Earth 10m 河流与 50m 陆地轮廓，墨卡托投影；水系沿线分别标示明代远航、清初军运和清代下游贡赏。数据版本及下载件 SHA-256 见 `map-sources.json`。
- 路线依文献关系覆于现代河道，并非逐日航迹。清代粮源经伊通河接入松花江的支路以正文说明，不虚构精确古道。
- 局部图仅示明代阿什哈达与清代西门外北岸船厂的位置关系，不绘厂界。明清两厂不处理为连续经营的同一机构。
- 瑷珲、特林是区域定位；贡赏图不把库页岛居民参与直接画成官船登岛。

## 实现与核验

地图 SVG 内置于 HTML，不请求远程地图瓦片。脚本负责三期切换、地点说明、缩放、拖移和键盘访问；正文和明代默认地图在禁用脚本时仍可阅读。封面直接由同一地图渲染。

已在系统 Chrome 检查 1440、768、390、360 像素宽度，核对图层显隐、键盘切换、地点选择、缩放重置及文献锚点。已检查主图三个时期、局部图及正文的截图，无横向溢出和 JavaScript 页面错误。这是浏览器视口检查，不等于真实手机硬件验收。

部署沿用现有 GitHub Actions / EdgeOne 流程；发布后应再次核对正文、脚本、样式、下载稿、封面和各入口。
