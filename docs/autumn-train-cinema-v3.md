# 金秋专列 · 自动观影版

本次将原来的循环交互场景改为 **150 秒的完整旅程**。原本桌面有五种视角、车速、日光切换和三个声音分层开关；新版开场只需点击一次“开始这段旅程”，观看中保留暂停、静音和全屏，结束后可重播。联系方式沿用原作品。

## 重新分析后的调整

- **先看列车，再理解旅程。** 开场用偏置构图留出标题，列车成为清晰主体；开场后标题退场。
- **用景别组织节奏。** 17 个镜头在随车、侧面、车头、机车近景、站房和河谷全景之间剪辑。切换直接到新机位，避免相机跨越整个山谷的快速飞移。镜头内部仅有缓慢移动。
- **四站有停顿，信息不占满画面。** 鹤岗、伊春、牡丹江、佳木斯各停留约十秒，只显示城市、一句意境和一行景区名；移除景区卡片、速度表、路线操作和常驻品牌标题。场景是山河意象，不宣称真实线路复原。
- **画面连续变化。** 保留程序化山林、机车连杆、水面反射；加入少量飘叶、按固定时间变化的烟雾，光线从日间逐步转为夕照。相机检查地形与树冠高度，改善前景遮挡。手机单独计算构图距离。
- **解说留白。** 六段新录 MiniMax `speech-2.8-hd / doc_commentary` 旁白共约 52 秒，语速 0.96；其余时间交给风景、配乐和火车声。保留原作品不显示逐句字幕的习惯。
- **配乐形成乐句。** 三段新生成的火山引擎 `GenBGMForTime v5.0` 器乐，以钢琴、大提琴、木管与轻弦乐围绕统一动机展开，八秒衔接。旁白期间音乐平滑降低，片尾自然收声。旧的循环电子音符已移除。
- **声音驱动画面。** 使用最终混音的 `currentTime` 作为播放时钟，暂停、切后台、重播时音画一起变化，低帧率不会拖慢剧情而导致配音先走。

## 文件与验证

- `小兴安岭金秋专列纪行.html`：离线单文件，画面与声音均内嵌。
- `web/index.html`、`web/journey-v3.mp3`：网站版。声音独立缓存，HTML 约 0.7 MB，开场加载更轻。
- `app.js`、各场景 JS、`style.css`：程序化画面和播放控制源码；`build.py` 构建两个版本。
- `generate_voice.py`、`generate_music.py`、`mix_audio.py`：音频复现；账号仅从当前机器的环境和已有适配器读取。
- `audio/lines.json`：实际语音时长与时间线；`audio/music-v3/`：乐段、生成记录与源音频。
- `review/`：桌面 1440×900、手机 390×844 的关键帧与播放检查。验证实际音轨播放、暂停不漂移、静音、完整四站、结尾、重播、无横向溢出和无 JavaScript 错误。当前机器缺少 Playwright WebKit 运行时，本次 Safari 未实际测试。

复现：音频生成完成后运行 `python3 mix_audio.py`，再运行 `python3 build.py`。浏览器需首次点击启用声音。
