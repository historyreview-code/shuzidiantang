# 投资研究站权限化迁移方案

> 目标：投资 AI 报告与每日晨报主要供本人查阅，未来申请新域名后独立管理，并设置权限访问。

## 1. 当前状态

投资研究内容当前位于主站仓库：

- `hidden/invest/`
- `hidden/invest/notes/`
- 自动发布脚本在 `~/digitalhall运营/每日晨报发布/`

当前保护方式：

- `robots.txt` 屏蔽 `/hidden/`
- 页面带 `noindex, nofollow`
- 主站导航不暴露入口

这只能降低被发现概率，不能提供真正权限控制。

## 2. 短期方案

新版主站 v2 继续保留历史 `/hidden/invest/` 路径，但遵守以下边界：

- 不放入主站导航。
- 不放入公开首页。
- 不放入公开作品馆。
- 不放入公开 sitemap。
- 组装脚本可以继续生成列表和 RSS，方便本人临时访问。

同时，新的投资内容不应再作为主站内容定位的一部分。

## 3. 中期方案：独立受保护研究站

建议新建私有仓库：

- `digitalhall-research`

建议部署路径：

- 申请新域名前：使用临时子域或服务器路径。
- 新域名到位后：迁移到独立域名，例如 `research-xxx.com`。

权限方式优先级：

1. 轻量服务器 + Nginx Basic Auth
   - 简单、可靠、成本低。
   - 适合个人查阅和少量朋友访问。
2. Cloudflare Access / Zero Trust
   - 适合后续需要邮箱登录、设备校验。
   - 需要域名接入 Cloudflare。
3. 前端口令页
   - 只适合临时挡入口。
   - 不能保护源码、网络请求或静态资源，不作为正式方案。

## 4. 晨报发布脚本改造方向

当前脚本把晨报写入主站：

```text
~/游戏创作/数字殿堂/hidden/invest/notes/
```

迁移后改为：

```text
~/游戏创作/digitalhall-research/notes/
```

脚本需要调整：

- `REPO_DIR`
- `NOTES_REL_DIR`
- 站点模板里的品牌、返回链接、RSS 链接
- git remote 与 push 目标

## 5. 新版主站处理原则

主站只作为公开作品馆：

- 可以在代码中保留 `hidden/` 复制逻辑作为短期兼容。
- 不在新版 IA、导航、首页、作品馆、视频页里提投资研究。
- 新域名和权限站准备好后，再从主站仓库移除 `hidden/invest/`。

## 6. 历史内容清理提醒

如果未来决定让投资内容彻底不公开，仅删除文件还不够，因为公开 GitHub 仓库历史中仍可能保留旧内容。

可选处理：

- 新建私有研究仓库并迁入内容。
- 主站删除 `hidden/invest/` 后，视需要清理 Git 历史。
- 对 GitHub Pages 已发布缓存进行失效等待或重新部署。

在没有明确隐私要求前，不建议贸然重写公开仓库历史。
