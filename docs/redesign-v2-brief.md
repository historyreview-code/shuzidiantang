# 数字殿堂 v2 改版 Brief

> 分支：`redesign-v2`
> 状态：架构与视觉改版基准，不直接代表线上内容。

## 1. 新定位

数字殿堂 v2 是一个个人数字作品馆，核心表达为：

> 收藏 AI 共创的编程作品、互动实验、视频创作与实践手记。

主站不再以“每日文章流”为第一叙事，而是以“作品 + 实践 + 审美”作为第一印象。

## 2. 内容边界

### 主站公开内容

- 数字作品：数字地球、网页游戏、天文馆、地图/旅行工具、其他 AI 编程实验。
- AI 实践手记：vibecoding、工具链、建站复盘、AI 工作流、代码与创作方法。
- 视频作品：B站、小红书两类作品入口，按平台和主题展示。
- 关于我：创作理念、工具栈、社媒联系、项目源代码入口。

### 投资研究内容

投资 AI 报告与每日晨报不再作为主站内容运营。

- 当前短期：可以保留历史 `/hidden/invest/`，但不进入主站导航、首页、sitemap 或公开作品列表。
- 中期：迁出为独立“研究站”，设置权限访问。
- 长期：申请新域名后独立管理，不再依附 `shuzidiantang.com`。

原因：

- GitHub Pages 不能提供真正的访问权限控制。
- `/hidden/` 只是路径隐藏，不是安全方案。
- 投资研究是个人查阅资料库，与公开数字作品馆的品牌气质不同。

## 3. 视觉目标

新版视觉应从当前“深空黑蓝 + 比特青紫霓虹”的单一科技感，升级为“数字美术馆”。

关键词：

- 有艺术感，不只是技术展示页。
- 有交互记忆点，但不过度炫技。
- 深色可以保留，但减少网格、霓虹和堆叠光效。
- 使用真实作品截图、视频封面、3D/Canvas 装置形成第一视觉信号。
- 中文排版要适合长读；作品卡要像展签，不像普通 dashboard 卡片。

参考方向：

- 作品即入口：Bruno Simon 式的强记忆点，但不做完整游戏化导航。
- 互动解释：Nicky Case / Josh Comeau / Sam Who 式的可读、可玩、可理解。
- 数字花园：Maggie Appleton 式的主题知识地图，不按流水账堆文章。
- 个人审美：Lynn Fisher / Rauno Freiberg 式的鲜明但克制的个人表达。

## 4. 推荐信息架构

### 首页

- 首屏：数字殿堂中庭，展示个人数字作品馆气质。
- 代表作品：数字地球、游戏厅、天文馆、AI 工具/实验。
- AI 实践手记：最新与精选并重。
- 视频作品：B站与小红书精选作品墙。
- 社媒与联系：GitHub、B站、小红书、公众号/视频号、邮箱。

### 作品馆

- 作品列表按“数字地球 / 游戏 / 影像与天文 / 工具实验 / 地图旅行”分组。
- 每个作品有独立详情页：简介、截图/视频、技术栈、AI 参与方式、源码/访问入口、复盘文章。

### AI 手记

- 从时间流改为主题流：
  - AI 编程
  - 工具链
  - 建站运营
  - 作品复盘
  - 视频工作流
- 保留 RSS 和日期归档，但不要让“每天一篇”成为首页压力。

### 视频作品

- B站：适合展示长视频、系列内容、科普/作品讲解。
- 小红书：适合展示短视频、图文卡片、生活化创作过程。
- 技术实现上先用“封面卡片 + 外链”，B站精选视频可后续接 iframe 播放器。
