# 一念成宇宙 · 网站开场

将原约 11.85 秒片头替换为 5.8 秒动画，加 0.4 秒淡出。沿用本网站自有纸纹、字体、琥珀色和探索主题；AI 是视觉表达，不调用模型服务。

## Design DNA

1. **纸色作为归宿**：首页以米纸为基底；片尾采用同一 `#f6f1e5`，淡入真实首页。
2. **墨色与琥珀分工**：沿用网站墨色正文、琥珀强调；夜幕中的神经连线使用暖金色，题字的「实验室」使用原琥珀色。
3. **书法承担品牌识别**：复用已有 MaShanZhengFilm 字体，文字使用 DOM 保持清晰；字体异步加载，不延长开场。
4. **数字地球转化为 AI 球体**：球面节点、传播中的光点与轨道表达数字、AI、探索三个主题。
5. **电影感来自连续镜头**：光点唤醒、散点聚合、球体旋转、加速穿越、纸面落字连续衔接；颗粒与宽银幕边框控制在背景层。
6. **短时、可跳过、适配手机**：5.8 秒后交接；跳过按钮、Escape、会话内一次、减少动态效果和失败兜底均保留或完善。手机题字分两行。

| 网站现有元素 | 转译规则 | 应用位置 |
|---|---|---|
| 米色纸纹、胶片颗粒 | 从暗场回到纸面 | Canvas 底色、颗粒、淡出 |
| 毛笔主标题 | 保留已有字体与墨/琥珀双色 | 片尾品牌题字 |
| 数字地球与天文作品 | 节点球体、经线、轨道 | 0.45–3.35 秒主体 |
| 数字 · AI · 探索 | 人的好奇心与 AI 共创 | 字幕、片尾眉题 |
| 克制的编辑式排版 | 宽留白、少量标注 | 角标、字幕、片尾 |

## 时间轴

- 0–0.7 秒：暖色光束唤醒散落的节点。
- 0.7–2.65 秒：节点汇聚，神经连接沿球体传播，轨道旋转。
- 2.65–3.8 秒：镜头向球体推进，纵深拖线带入纸面。
- 3.75–5.8 秒：品牌题字与「数字 · AI · 探索」落定。
- 5.8–6.2 秒：淡出并恢复首页入场。

## 验证结果

- 桌面 1440×900、手机 390×844、横屏 844×390 已截图并检查。
- 实测从页面就绪到开场完全移除约 6.6 秒，动画本体 5.8 秒。
- 自动结束、会话内一次、主动重播、按钮跳过、Escape、减少动态效果、脚本加载失败、存储被禁用、无 JavaScript 均通过。
- 浏览器无脚本错误、无失败资源请求；主站构建通过。
- 修正首页原有轮播造成的手机横向溢出：响应式网格允许收缩，轮播圆点允许换行。
- 未做真机低端设备性能测量；全站作品组装由现有 EdgeOne 发布流程执行。

## 粒子色彩定稿

金色占主导，增加青绿（119,207,193）和暖橙（240,155,119）的节点、传播光点、轨道与穿越拖线。色彩只用于暗场粒子层，纸面品牌题字继续沿用原站墨色与琥珀色。局部柔光增强前后景层次，不增加粒子数量或第三方依赖。
