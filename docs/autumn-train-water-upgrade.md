# 秋日列车水面升级 · 2026-09-25

## 行为变化

水面保留原有河道、真实场景倒影和泡沫，加入交错细波纹、柔和近岸光纹、视角相关反射和远景高光过滤。日光与夕照均跟随原场景色调。

修正原水面法线与波形导数不一致的问题；屏幕导数在岸线裁切前计算。相机大幅切换时立即刷新倒影，减少旧倒影残留。

默认开启增强。持续平均帧耗时超过 26 ms 达 3 秒，逐渐关闭新增细节并将倒影更新从每 3 帧降为每 4 帧；持续低于 19 ms 达 8 秒后恢复，避免反复跳档。暂停、隐藏标签页和单次长卡顿不参与降档判断。

## 资源预算

- HTML：1,995,804 → 1,998,589 字节，增加 2,785 字节（约 0.14%）。
- 保持原 768×512 倒影缓冲、最高 1.65 像素密度。
- 没有新增几何体、纹理、外部请求或后期渲染步骤。
- 不包含完整 FFT、水波交互模拟或镜头衍射眩光。

## 验证

Apple M4 本机运行 Chrome 和 Playwright WebKit 26.5。两种引擎均通过：

- shader 编译与运行，无浏览器错误；
- 手机横竖屏布局、自动运镜、四站顺序、景区卡片与第二圈循环；
- 配音、配乐、音效、暂停／恢复、独立声道开关及手机静音／重新开启；
- 日光、夕照、近岸水面与鸟瞰截图检查。

额外测试持续低帧率降档、恢复迟滞、60/120 Hz、暂停、隐藏页面和长卡顿处理。升级前后同场景、同视口，按前／后／后／前顺序取样，纹理、几何体及 shader program 数量一致。手机视口 393×852、deviceScaleFactor 3（实际渲染仍受 1.65 上限约束）；桌面 1440×900。

WebKit 最终版本性能摘要见附表。此对照为固定场景的 requestAnimationFrame 间隔，受垂直同步限制；不能据此声称 GPU 耗时完全相同。Chrome 首轮对照同样约 60 fps，最终版本完成 Chrome 功能回归。

没有使用 iPhone 真机；未覆盖真机 Safari、微信内置浏览器、热降频和续航。近岸光纹是艺术化效果，不是真实河床折射模拟。

## 参考与维护

设计思路参考 https://github.com/Aureliengmz/clearwater ，本次在现有水面 shader 内独立实现，未引入其代码或素材。

本地源项目：`outputs/autumn-train/`；修改 `water.js` / `app.js` 后运行 `python3 build.py`，再同步 `public/autumn-train/index.html`。测试副本与其专用相机钩子不发布。诊断可读取 `window.autumnTrain.getState().water`。

回退时恢复本次提交前的 `public/autumn-train/index.html` 即可。
