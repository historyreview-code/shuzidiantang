# 黄河 · 改道两千年

一个纯静态的黄河历史改道交互展示：前 602 年至 1947 年，黄河决口 1593 次、较大改道 26 次；本页以「六大迁徙」为骨架，加上 1128、1938 两次大规模人为决河，把这条河两千年里「善淤、善决、善徙」的故事放在一张可滚动、可拨动的地图上。

本地预览：

```bash
python3 scripts/dev-server.py 8137
# 打开 http://localhost:8137/
```

## 三种使用方式（模式）

1. **叙事模式（默认首页往下滚）**：左侧十章文字（序 + 八次改道 + 尾声），右侧地图 sticky 跟随，滚到哪章，地图镜头飞到对应区域、高亮当年的河道、标出决口点。
2. **图鉴模式（「图鉴 · 亲手拨两千年」区）**：点朝代按钮或拖时间轴，河道按当年实际流路显影、废弃故道退为残影；可播放全程动画（约 35 秒）、「全览河道」一次看尽所有流路、开关省界/水系/堤防/决口点/城邑/河名图层、滚轮缩放拖拽平移。
3. **一览模式（附录）**：改道一览表（年份 / 决口处 / 改道后入海 / 行用时间 / 自然或人为），加来源与说明。

深链参数（可分享某个历史时刻）：

- `?era=e1194` —— 直接定位某次事件，id 见 `js/data.js` 的 `EVENTS`（如 `e602` `e11` `e1048` `e1128` `e1194` `e1495` `e1855` `e1938`）
- `&atlas=1` —— 进入全览河道
- `&instant=1` —— 跳过动画直出状态（截图、低性能环境、或配合系统「减弱动态效果」偏好）

`prefers-reduced-motion: reduce` 时自动等效 `instant`。

## 技术与数据

- **零依赖、零构建**：原生 ES Modules + 本地打包的 D3 v7（`vendor/d3.min.js`），无外链、无 API key，可离线渲染。
- **底图**：阿里云 DataV GeoAtlas 省界（`scripts/simplify.mjs` 抽稀 + 环向重绕后 336KB 随站打包）。注意 DataV 原始 GeoJSON 外环为逆时针（RFC 7946），与 d3 球面几何的顺时针约定相反，直接渲染会得到反相掩膜——脚本内已用 `d3.geoArea` 检测并翻转。视野 fit 用 `MultiPoint` 而非 Polygon，避免同类缠绕歧义。
- **历史河道**：`js/data.js` 中每条河道是依据文献记载概化的经行点列（非精确复原）：禹河故道、前602漯川、汉唐千乘故道、商胡北流、二股河东流、金初泛道、明清夺淮河道、今河道（1855，1938–1947 断流段单独处理）、花园口泛道（颍/涡两支），另有太行堤、淮河与大运河参考线、洪泽湖等。
- **史实口径**：决口 1593 次、较大改道 26 次、六大迁徙（黄河水利委员会统计，前602—1946）；夺淮 727 年（1194–1855）；1855 铜瓦厢为最近一次自然大改道。各家计数略有出入处已在页面注脚说明。

重新处理底图（改抽稀精度时）：

```bash
node scripts/simplify.mjs 0.02 0.004   # 容差（度）、碎小岛面积阈值
```

## 部署

已并入劳伦斯实验室主站：本目录随仓库发布，`npm run assemble` 会把 `maps/` 拷进 dist，线上地址 `/maps/huanghe/`（作品页与地图馆均有入口）。

若要独立部署（EdgeOne Pages 等）：整个目录即静态站，无构建命令，输出目录即根目录；单文件最大 336KB，远低于免费版 25MB 限制。

## 目录结构

```
index.html            页面骨架
css/style.css         纸上舆图风格样式
js/data.js            河道/事件/章节/表格数据（史实与坐标都在这里改）
js/map.js             地图组件（叙事图与图鉴图共用工厂）
js/main.js            页面装配与交互
vendor/d3.min.js      D3 v7 本地副本
data/china-provinces.geojson   简化+重绕后的省界
data/_raw/            DataV 原始下载（勿部署亦可，页面不读它）
scripts/simplify.mjs  抽稀 + 环向重绕
scripts/dev-server.py 本地预览（no-store，调试用）
```
